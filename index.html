Security · Swift PackageBanking

SecureBankKit

Problem
Every banking app rebuilds Keychain storage, Face ID, session timeouts and jailbreak checks, and small mistakes become audit findings.
Approach
Six focused modules (Keychain, Biometrics, Session, Security, Utils, Core) so a team adopts only what it needs, with a SwiftUI demo app.
Result
Token storage, biometric app lock on background, inactivity timeout with token refresh, and logging that redacts sensitive data in one dependency.

Waypoint

Problem
NavigationStack apps end up with stringly-typed links, modal state scattered across views, and navigation nobody can unit-test.
Approach
Codable route enums, one @Observable router per stack and modal, guards that run before navigation commits.
Result
Deep links with host allow-listing, nested modals, per-tab stacks and state restoration, all testable without rendering a view.

SwiftBLEKit

Problem
Bluetooth code is usually tested by hand with a device on the desk, so reconnection bugs reach users.
Approach
A protocol boundary over CBCentralManager with a mock central and simulated peripherals, and an injectable sleep for deterministic backoff tests.
Result
Reconnect with exponential backoff and jitter, a GATT profile DSL, typed heart-rate and battery models, and a priority connection pool.

WaypointTests.swift
@Test @MainActor func signedOutUsersSeeLogin() {
    let router = Router<AppRoute> { $0 == .settings ? .present(.login, style: .sheet) : .allow }

    router.push(.settings)

    #expect(router.path.isEmpty)
    #expect(router.sheet?.root == .login)
}

Routers are plain observable objects, so a guard's behaviour is checked in a unit test with no simulator and no view rendering.

DeepLinks.swift — Waypoint
var links = Self(schemes: ["myapp"], hosts: ["example.com", "www.example.com"])

links.register("users/:id") { match in
    match["id"].map { NavigationState(path: [.profile(userID: $0)]) }
}
links.register("articles/:id") { match in
    match.int("id").map { NavigationState(path: [.article(id: $0)]) }  // nil if not a number
}
links.register("login") { _ in
    NavigationState(presented: .init(style: .sheet, root: .login))
}

Universal links and custom schemes resolve to typed navigation state. Unknown hosts are rejected, and malformed IDs return nil instead of crashing.
